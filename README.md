# React To-Do Application

A modern, responsive To-Do list application built with React and Tailwind CSS. This project was created to demonstrate fundamental React concepts including component architecture, state management, and modern styling techniques.

## ✨ Features
*   **Add Tasks:** Quickly add new tasks to your list.
*   **Mark as Done:** Visually strike-through completed tasks.
*   **Filter Tasks:** Filter your view by "All", "Done", or "Todo".
*   **Delete Tasks:** Remove individual tasks or clear all completed tasks at once.
*   **Modern UI:** Styled with Tailwind CSS for a clean, responsive, and interactive design.

## 🚀 Tech Stack
*   **React** (via Vite)
*   **Tailwind CSS** (v3)
*   **React Icons** (FontAwesome icons)

## 🛠️ Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing.

### Prerequisites
You need to have Node.js installed on your computer. You can download it from [nodejs.org](https://nodejs.org/).

### Installation

**1. Clone the repository**
Open your terminal and run the following command to clone the project to your local machine:
```bash
git clone https://github.com/2002Sanjai/To_Do_Project.git
```

**2. Navigate into the project directory**
```bash
cd To_Do_Project
```
*(Note: If you named your folder differently during cloning, use that folder name instead).*

**3. Install dependencies**
Install all the required node modules (React, Tailwind, etc.):
```bash
npm install
```

**4. Start the development server**
Run the Vite development server:
```bash
npm run dev
```

**5. Open in Browser**
Once the server starts, it will provide a local URL (usually `http://localhost:5173/`). Open that URL in your web browser to see the app!
